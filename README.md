# python-inheritance-oops-practice

# Python Inheritance & OOP Practice

A collection of Python programs to practice Inheritance, Polymorphism,
Operator Overloading, Properties, and other Object-Oriented Programming concepts.

## Practice Questions

### Q1. 2-D and 3-D Vector
Create a class representing a 2-D vector and use it to create another class representing a 3-D vector.

[View Solution](Q1.py)

### Q2. Animals, Pets and Dog
Create a class `Pets` from a class `Animals` and further create a class `Dog` from `Pets`. Add a `bark()` method to the `Dog` class.

[View Solution](Q2.py)

### Q3. Employee Salary and Increment
Create a class `Employee` with salary and increment properties. Implement `salaryAfterIncrement` using a `@property` decorator and setter.

[View Solution](Q3.py)

### Q4. Complex Numbers
Create a class `Complex` to represent complex numbers and overload the `+` and `*` operators.

[View Solution](Q4.py)

### Q5. Vector Class
Create a vector class representing a vector of n dimensions. Overload the `+` and `*` operators to calculate vector sum and dot product.

[View Solution](Q5.py)

### Q6. Vector String Representation
Implement the `__str__()` method to display a 3-dimensional vector in the following format:

`7i + 8j + 10k`

[View Solution](Q6.py)

### Q7. Vector Length
Override the `__len__()` method on the vector class to display the dimension of the vector.

[View Solution](Q7.py)
